Chapter 02 · Rezoning

Who has to be told

The petition (made up): a developer asks the Town of Sheboygan to rezone the field from I-1 Light Industrial to a Planned Unit Development: townhomes and apartments that continue the R-4 complex next door, a small commercial corner on Playbird Rd, and a stormwater pond and trail along the wooded south edge.

The rules (real): the Town's zoning code (Ch. 335, Art. XII) asks for the names and addresses of every owner within 200 ft, a plot plan at 1 in = 100 ft showing adjacent districts and uses, and written notice at least 10 days before the hearing to the clerk of any municipality within 1,000 ft. The Plan Commission holds the hearing; the Town Board decides.

This is the request a planning office sends its GIS technician more than any other. I ran it by hand in ArcGIS Pro first, then wrote a Python toolbox that does it in one step and checked that both gave the same answer.

The tool

An ArcGIS Pro Python toolbox (Pro 3.7.3, nothing to install beyond Pro). Give it a parcel layer, one or more parcel IDs and a notice distance.

  1. Select. Every parcel within the distance, from the whole layer even if something else is selected, so it matches the hand method exactly.
  2. Clean. One letter per owner. Right-of-way and blank owners are set aside with a reason; spelling variants at one address are merged; look-alike names are listed in a review file instead of being merged.
  3. Flag. Absentee owners (mailing address differs from the parcel's address), the petitioner's own parcels, and owners with several parcels.
  4. Clerks. Any other municipality with land within 1,000 ft, read from the parcels' municipality field.
  5. Output. Avery 5160 label sheets, the mailing list and every parcel's letter number as CSV, a summary, and the notice map: the tool builds the map and the layout itself (title, counts, legend, north arrow, scale bar, sources) and exports it at the scale the code asks for.

The list logic is plain Python with tests, separate from the arcpy part, so it can be checked without ArcGIS. The tool's counts matched my hand run in Pro: 29 parcels, 17 owner rows, 15 letters, one clerk.

Found along the way
  • Two towns, one hearing. Playbird Rd is the line between the Town of Sheboygan and the Town of Mosel. A rezoning on one side has to be noticed on the other.
  • A city's reach. The county's extraterritorial jurisdiction layer puts the field inside the City of Sheboygan's ETJ, so the plat in chapter 3 will likely need city review as well as the Town's and the county's.
  • The petitioner gets a letter. Owners of land inside the petition are on the list too; the tool marks them so staff can treat that letter differently.
My role
